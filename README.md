# University Student Analytics Dashboard

Este proyecto analiza datos de admision, matricula, satisfaccion estudiantil utilizando python y Streamlit.

## Objetivo del proyecto
El objetivo de este dashboard es visualizar y resumir de forma interactiva la informacion estudiantil de la universidad para apoyar la toma de decisiones basada en datos.

## Caracteristicas 

- Filtros interactivos por año y periodo academico
- Analisis de tasas de retencion
- Analisis de satisfaccion estudiantil
- Visualizacion de metriculas por departamento
- Indicadores KPI
- Graficos y tablas dinamicas

# Tecnologias usadas

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Archivos incluidos

- 'app.py' => Dashboard principal en Streamlit
- 'requirements.txt' => librerias necesarias
- 'README.md' => Documentacion del proyecto
- 'university_student_data.csv' => Dataset utilizado en el analisis
